## Sales & Inventory KPI Dashboard

This module provides a **Sales & Inventory KPI Dashboard** in Odoo 18.0, offering key business insights:

### **Key Features**
-  **Total Sales, Orders, Stock** – Displays essential KPIs for business monitoring.
- **Manual Refresh** – Users can update data instantly.
- **Simple UI Styling** – Clean and modern design.

### **Installation**
1️⃣ Copy the module to your Odoo addons folder.  
2️⃣ Run `odoo-bin -u your_module_name --db-filter=<your_db_name>` to update the module.  
3️⃣ Access via **Reporting > KPI Dashboard** in Odoo.
